# Next-Trip 2.0
Sistema de dados de países e suas curiosidades

## Alguns campos que podemos preencher com dados dos Países: 

* Nome
* População
* Curiosidade
* Prato Típico - 
* Localização - 
* Esportes -
* Imagem da Bandeira
* Status - Já Visitou, Quer Visitar e se Não Quer Visitar


## Foram utilizadas as seguintes tecnologias:

* Django Framework
* Pillow – para manipulação de imagens (bandeiras)

## Para executar na sua máquina você pode seguir esses passos:

* Baixe o zip do repositório
* Crie sua venv na pasta do projeto
* Instale as dependências do requiriments.txt
* Caso seja necessario, faça as migrações
* Rode com Python manage.py runserver


## Ao executar, você pode acessar as seguintes rotas:

* http://127.0.0.1:8000/admin
* http://127.0.0.1:8000/api/paises/
